# MB World — 서비스매니저 라운지

매니저들이 휴대폰이나 PC 브라우저로 링크만 열면 들어오는 3D 실시간 공간이에요. 앱을 설치하거나 Claude에 가입할 필요가 없어요.

## 들어 있는 것
- 3D 월드: 쇼룸, 회의실, 서비스 라운지, MB 광장, 워크숍, 카페, 테스트 트랙
- 실시간으로 같이 돌아다니기, 말풍선 채팅, 리액션
- 액티비티: 볼트 108회 조이기, 광택 내기, 오늘의 응대 수행(퀴즈), 랩타임, 분수 다짐, 커피
- 정비 포인트, 연속 출석, 랭킹, 오늘의 다짐 벽
- 모바일 조이스틱, 탭으로 이동, 핀치 줌, 📱 초대 QR

## 가장 빠른 방법: Render(무료)에 올리기
1. 이 폴더를 GitHub 저장소에 올립니다(비공개 저장소도 됩니다).
2. https://render.com 에 가입하고 **New → Web Service**에서 그 저장소를 고릅니다.
3. 설정값:
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Environment: `ACCESS_CODE` = 원하는 입장 코드(예: `mb2027`). 비워두면 링크만 있으면 누구나 입장할 수 있어요.
4. 배포가 끝나면 `https://○○○.onrender.com` 주소가 나와요. 이 주소(또는 앱 안의 📱 초대 QR)를 매니저들에게 공유하면 됩니다.

참고: Render 무료 플랜은 15분 동안 아무도 없으면 잠들어서, 다음 첫 접속 때 30초쯤 걸려요. 서버를 다시 배포하면 채팅·포인트 기록이 초기화돼요. 기록을 계속 남기려면 유료 플랜에서 Disk를 붙이고 `DATA_DIR`을 그 경로로 지정하세요. Railway나 Fly.io도 같은 방식으로 올릴 수 있어요.

## 사내 서버나 PC에서 실행
```bash
npm install
ACCESS_CODE=mb2027 npm start      # Windows PowerShell: $env:ACCESS_CODE="mb2027"; npm start
```
`http://서버주소:3000` 으로 접속하면 됩니다. 외부(파트너사) 휴대폰에서 들어오려면 HTTPS 주소가 필요하니 사내 IT와 협의하세요.

## 환경 변수
| 이름 | 설명 |
|---|---|
| `PORT` | 포트 (기본 3000) |
| `ACCESS_CODE` | 입장 코드. 비우면 코드 없이 입장 |
| `DATA_DIR` | 채팅·포인트 저장 폴더 (기본 `./data`) |

## 운영 메모
- 사람마다 기록은 브라우저에 저장된 개인 토큰으로 구분해요. 다른 기기로 들어오면 새 기록으로 시작해요.
- 퀴즈(12문제)와 오늘의 한마디(10개)는 `index.html` 안의 `QUIZ`, `QUOTES` 목록을 고치면 바뀌어요.
- 외부 서버에 올리기 전에 사내 보안 정책(외부 호스팅, 파트너 정보)을 확인하세요.
